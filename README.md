# Kompilyatorga Qarshi Shikoyat Arizasi ⚖️💻

365 kunlik ijodiy loyihalar challenge — **25-kun**.

Kodingiz ishlamayaptimi? Buning aybdori siz emassiz — bu Kompilyator! Xatoligingizni tasvirlab bering (yoki yozmang), dastur rasmiy sud shikoyat arizasini tayyorlab beradi.

## Xususiyatlari

- Ixtiyoriy ravishda o'z xatoligingizni kiritish imkoniyati
- 18 ta hazil "ayblov moddasi" dan 4 tasi tasodifiy tanlanadi
- 6 xil "talab" jumlasi tasodifiy qo'shiladi
- Har safar tasodifiy ish raqami va bugungi sana
- Rasmiy sud hujjati estetikasi (Courier shrift, ish raqami, imzo joyi)

## Ishga tushirish

`index.html` faylini brauzerda oching. Hech qanday server yoki kutubxona kerak emas.

## Texnologiyalar

- HTML5 / CSS3 / Vanilla JavaScript
